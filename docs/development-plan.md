## 激活与导出

- 复用个人所得税项目既有的服务端激活码逻辑，以 Redis 中的有效激活码作为激活依据。
- 对接前核实既有服务、码类型、有效期、使用次数与绑定规则；隔离产品授权，避免修改或消耗个税产品已有授权。
- 激活结果与导出权限由服务端判定，不能只依赖前端按钮、浏览器本地标记或隐藏字段。
- 每次导出请求检查有效授权；文件生成与下载路径均受服务端保护，避免直接访问静态文件跳过授权。
- 正常授权后可以导出、下载并打开文件；导出文件不叠加产品水印。
- 过期、无效、撤销或不适用于本产品的授权，按实际规则返回清晰提示。

安全目标是防止通过修改前端状态、直接请求接口或访问文件地址绕过服务端授权；不作“任何情况下绝对无法绕过”的承诺。

## 上线验收

| 场景 | 预期结果 |
| --- | --- |
| 有效激活码 | 服务端确认授权，按规则允许导出 |
| 无效或过期激活码 | 激活失败，无法取得导出文件 |
| 修改浏览器本地激活状态 | 无法获得未经服务端授权的导出文件 |
| 跳过页面直接请求导出接口 | 仍须通过服务端授权校验 |
| 直接访问下载地址或复用失效授权 | 按文件访问和授权有效期规则校验 |
| 授权导出 | 文件成功生成、完整下载并正常打开，无产品水印 |
| 中文与排版 | 字体、换行、日期和页面尺寸符合选定模板 |
| 手机与电脑 | 在实际选定的浏览器与设备上检查预览、激活与下载 |

具体文件格式、兼容设备和激活使用规则在开发时依据现有代码与选定模板落实，发布前更新真实验证结果。
