# 离职证明演示工具实现与验收记录

2026-11-08 已部署：[宣传入口](https://geshui-apk.moujc.cn/leave-certificate/) · [在线工具](https://geshui-apk.moujc.cn/leave-certificate/editor.html)。技术交流学习，联系 QQ **2430239942**。

## 已实现

- 产品集合宣传页同时介绍离职证明和个人所得税模拟器，保留原始版式截图及联系方式。
- 示例资料编辑、公章设置、带水印 PNG 预览、服务端生成单页 A4 中文 PDF。
- 采用个税同类的 P256 安装签名、60秒一次性挑战和 Redis Lua 原子激活；产品授权前缀隔离。
- 每次导出重新检查服务端授权，签名绑定本次资料；无水印文件不写入公开静态目录。
- 激活码一次性使用，已用码保留摘要。刷新浏览器可恢复安装授权，撤销后不能继续导出。
- 下载与打印使用同一受授权保护的 PDF；草稿留在本浏览器，服务端不持久保存证明资料或生成文件。

## 已完成验证

| 场景 | 结果 |
| --- | --- |
| 未激活或伪造前端状态导出 | 被拒绝 |
| 无效码、已用码、同一码并发激活 | 无效/已用码失败，并发只有一个安装成功 |
| 修改资料摘要、伪造签名 | 被拒绝 |
| 一次性挑战重放、失效挑战 | 被拒绝 |
| 删除安装授权、渲染期间撤销 | 无法取得 PDF |
| 授权存储故障 | 模拟故障时关闭导出通道；没有中断共享 Redis |
| 外站来源、过大正文、无效格式与请求限速 | 按规则拦截 |
| 猜测下载地址或访问服务端文件 | 无公开 PDF 地址，私有路径不可访问 |
| 授权导出 | 实际下载 PDF 可打开、中文可读、单页 A4、不叠加产品水印 |
| 桌面与手机布局 | Chrome 1440、768、390宽度通过，未发现横向溢出 |
| 真实线上 HTTPS 接口 | 激活、码消费、导出、重放拒绝与撤销拒绝通过；自测授权已清理 |

本地服务端16项测试通过，复用本机 Docker 中的 Redis 7.4 专属测试前缀；只清理自测键。线上复用既有 Redis 6.2.24 和 Caddy，保留原有个税 API 路由与下载页。未验证所有手机实机、Safari及各类内置浏览器；尚无独立渗透测试结论。

## 安全边界

安全目标是防止改前端状态、直接调用导出接口、重放请求或猜测下载地址跳过授权，不承诺任何情况下绝对无法破解。不能阻止已授权下载文件被复制、截图或另行重制。
